# Сверка с ROM *Insmouse no Yakata* (Virtual Boy)

**Файл:** `Insmouth_Mansion_Japan_T-En_Thunderstruck_v1.0.vb`
(прислан как `.jpg`, переименован обратно в `.vb`). Размер **1 048 576 байт**
(8 Mbit). Это не JPEG и не ZIP: первые байты `4e 82 00 07 ...` — код NEC V810.
 ROM с английским фанатским переводом Thunderstruck v1.0.

## 1. Заголовок Virtual Boy

По спецификации заголовок лежит по адресу `0x07FFFDE0` (для 1-МиБ образа —
смещение `0xFFDE0`):

```
0xFFDE0  49 6E 6E 73 6D 6F 75 74 68 20 4D 61 6E 73 69 6F 6E   "Innsmouth Mansion"
0xFFDF9  38 46                                                  maker  = "8F"
0xFFDFB  56 49 4D 45                                            game   = "VIME"
0xFFDFF  00                                                     version = 0
```

Образ подлинный, японский оригинал `VIME` (I'Max / Be Top, 1995), а не
переименованный движок `Mecasting.jpg`.

## 2. Таблица паролей (смещение `0x415C0`)

46 четырёхбуквенных слов подряд в ASCII — 45 уровней + `DEMO`:

```
ROPE ROAD LOVE ARCH IRON CAFE RUBY DOOR URAN AQUA HIGH WILD
MEAT WINE BODY JAZZ GAME BOOK BALL GUTS TANK MASK HAND WING
ADAM WOOD WALK WAVE WEAR CAKE EROS SNOW RAIN GOAL FISH BONE
BABY INCA FAKE ALPS ROCK FOOL EDEN HYDE DARK DEMO
```

Это прямое подтверждение структуры оригинала: **ROPE → … → HYDE**,
45 этажей, 13 за прохождение, 4 концовки. Пароль в нашей игре **убран по
явному требованию** и заменён RMS-автосохранением; ветвление по времени,
13 этажей и 4 концовки сохранены.

45 слов (без служебного `DEMO`) теперь подписывают узлы **карты продвижения
между этажами** (`Game.NODES` / `Game.nodeName()`): 13 колонок с числом узлов
`1,2,3,4,5,5,5,5,5,4,3,2,1`, ветвящееся красно-чёрное дерево, `ENDING A/B/C/D`
справа, орнаментальная кайма. Это названия этажей, а не пароли: ввод пароля
по-прежнему отсутствует, выбор ветки (`routeRow`) пишется в RMS.

## 3. Механика (FAQ Brian Hodges / MobyGames + карты ROM)

В картах FAQ отдельно помечены стены `B = Monsters can break through this wall`,
то есть пробой — **не любая стена**, а специально отмеченная. Наш аналог —
`Level.CRACKED` (≈5 % внутренних стен, им же соответствует текстура трещины).

| Наблюдение в ROM / FAQ | Что сделано в игре |
|---|---|
| 3 сердца, 6 пуль + запас, ключ → дверь, таймер 0:59…3:00, белый/чёрный шар | сохранено с первого забега |
| Твари стартуют на своих местах и **бродят**, не проходят через двери | `homeX/homeY` + блуждание в радиусе 3, `isWall` не пускает в двери |
| **Иногда пробивают стену** (`B` на картах) и нападают | `tryBreachWall()`: ломает `CRACKED`, шагает в пролом, телеграфированный выпад, 1 сердце |
| Урон только из **соседней клетки** | `manhattan <= 1` |
| **2–8 пуль на тварь**, число постоянно для каждой особи | `maxHp = 2..8` из частей тела, выстрел = ровно 1 HP |
| После попадания тварь уходит в сторону, может стрейфить | `fleeUntil` + боковые шаги при блуждании |
| Тварей нельзя пройти, только убить или обойти | толчок блокирует клетку без урона |
| **Таймер останавливается на экране карты** | `update()` не тикает при `showMap` |
| `Select` = карта; авто-пауза раз в 15 мин «дай глазам отдохнуть» | `#` = карта; **меню паузы на правой софт-клавише** (наша замена под J2ME) |
| Убрав оружие, прицел возвращается в центр | `7` при убирании сбрасывает `aimX/aimY` в центр экрана |
| После этажа показывается карта с мигающим следующим кружком, два маршрута по скорости | отдельный экран `PROGRESS` с деревом 45 узлов, быстрая ветка вверх / медленная вниз |
| Узкие коридоры и комнаты-«B» на картах этажей | 1-клеточные коридоры DFS, 1–2 крошечные квартиры, 7 % петель, суженный обзор и более плотный туман |

## 4. Что намеренно не копируется

Спрайты, тексты, парольный экран и японская типографика оригинала не
переносятся: сеттинг «Самосбор», процедурные монстры из частей тела,
кириллический bitmap-шрифт и J2ME-реализация — самостоятельные. Пароли
заменены автосейвом по прямому указанию, а не «как в ROM».
